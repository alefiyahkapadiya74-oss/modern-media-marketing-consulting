# Requirements: Modern Media & Marketing Consulting FZC

**Defined:** 2026-07-29
**Core Value:** Deliver an Awwwards-level cinematic, immersive, and highly memorable digital experience that positions Modern Media & Marketing Consulting FZC as one of the top luxury creative agencies in the UAE.

## v1 Requirements

### Core System & Design Tokens
- [x] **SYS-01**: Design system setup with luxury color palette (#234038 Forest Green, #B88A44 Brass Gold, #F7F4EC Warm Ivory, White, Charcoal).
- [x] **SYS-02**: Typography integration featuring Playfair Display for headings and Inter for body copy.
- [x] **SYS-03**: Smooth scroll provider powered by Lenis integrated into global app layout.

### Navigation & Header
- [x] **NAV-01**: Transparent navigation bar with smooth scroll background state changes on scroll down.
- [x] **NAV-02**: Sticky menu with interactive links navigating directly to section anchors.
- [x] **NAV-03**: Mobile responsive slide-over/overlay menu with high-end transition effects.

### Hero & Storytelling
- [x] **HERO-01**: Cinematic large typography hero section with editorial layout and Playfair Display heading.
- [x] **HERO-02**: GSAP text reveal and scale entrance animations on page load.
- [x] **HERO-03**: Call-to-action buttons ("Explore Our Work", "Consultation Request") with magnet/hover effects.

### About Section
- [x] **ABT-01**: Interactive About section introducing company origin, Sharjah Publishing City Free Zone base, and market position.
- [x] **ABT-02**: Visual layout for Mission, Vision, and Values with scroll-triggered fade/blur reveal effects.
- [x] **ABT-03**: "Why Choose Us" feature list with interactive card highlights.

### Services Suite
- [x] **SVC-01**: Showcase grid covering all 7 core consultancy domains: Marketing Consultancy, Media Buying, Brand Strategy, Web Development, Social Media Consultancy, Design Consultancy, HR Consultancy.
- [x] **SVC-02**: Service detail cards with interactive hover effects, subtle borders, and expanded detail views.

### Process Walkthrough
- [x] **PROC-01**: Interactive 6-step methodology showcase (Discovery, Research, Strategy, Execution, Optimization, Growth).
- [x] **PROC-02**: Horizontal or pinned scroll progress indicator for the 6 workflow steps using GSAP ScrollTrigger.

### Portfolio & Case Studies
- [x] **PORT-01**: High-impact Bento & Masonry portfolio grid displaying luxury project cards.
- [x] **PORT-02**: Image stacking, parallax, and zoom animations on hover/scroll for portfolio work.
- [x] **PORT-03**: Detailed Case Studies section detailing client challenge, solution, and growth metrics.

### Testimonials & Social Proof
- [ ] **TEST-01**: Elegant testimonial showcase with custom quote typography and high-profile client cards.
- [ ] **TEST-02**: Interactive slider or card transition for reviews.

### Contact & Location
- [ ] **CONT-01**: Functional inquiry contact form with client-side validation.
- [ ] **CONT-02**: Location details featuring Sharjah Publishing City Free Zone address, email, phone, and direct links.
- [ ] **CONT-03**: Interactive Google Maps embed with custom styled pin for agency headquarters.

### Animation & Motion Systems
- [ ] **ANIM-01**: Lenis smooth scroll inertia physics configuration.
- [ ] **ANIM-02**: GSAP ScrollTrigger pinning and parallax scroll effects across key sections.
- [ ] **ANIM-03**: Micro-interactions (hover scale, subtle magnetic buttons, custom cursor option).

## v2 Requirements

- **EXT-01**: Multi-language localization (Arabic & English toggle).
- **EXT-02**: Interactive project cost calculator for potential B2B clients.
