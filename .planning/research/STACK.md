# Project Research: Tech Stack

## Recommended Stack

### Framework & Core Architecture
- **Next.js 14+ (App Router)**: High-performance React framework providing Server-Side Rendering (SSR) for optimal SEO, fast image optimization (`next/image`), and streaming UI capabilities.
- **TypeScript**: Strict type safety across components, animation configs, and content schemas.
- **React 18+**: Concurrent rendering and server components support.

### Styling & Design System
- **Tailwind CSS**: Utility-first CSS for rapid layout design, custom theme extending `#234038` (Deep Forest Green), `#B88A44` (Brass Gold), `#F7F4EC` (Warm Ivory), White, and Charcoal.
- **Typography**: Google Fonts integration via `next/font` for `Playfair Display` (Headings) and `Inter` (Body).

### Motion & Animation Architecture
- **Lenis Smooth Scroll**: Modern inertia-based smooth scrolling library for physics-based scroll feel.
- **GSAP & ScrollTrigger**: Industry standard for complex timeline animations, scroll pinning, parallax, text reveals, and image stacking.
- **Framer Motion**: Component-level gesture and page transition micro-interactions.
- **Three.js / React Three Fiber (R3F)**: Targeted 3D canvas integration for cinematic ambient visuals where meaningful.

## Why This Stack
1. **Awwwards Standard**: GSAP + Lenis + Next.js + Tailwind is the gold-standard stack used by top award-winning agencies.
2. **SEO & Speed**: Next.js App Router delivers fast initial load times and clean meta tag rendering essential for agency discoverability in UAE.
3. **Immersive UX**: Lenis scroll physics paired with GSAP ScrollTrigger ensures butter-smooth scroll animations without frame drops.
