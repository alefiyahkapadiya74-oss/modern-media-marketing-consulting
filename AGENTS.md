## Project

**Modern Media & Marketing Consulting FZC**

Modern Media & Marketing Consulting FZC is a luxury, modern, editorial, and interactive web application for a premier UAE-based creative marketing and business consulting agency located in Sharjah Publishing City Free Zone. The platform offers an immersive storytelling experience with smooth animations, high-end typography, and an Awwwards-inspired aesthetic to showcase the company's full service suite across marketing, branding, web development, media buying, and HR consulting.

**Core Value:** Deliver an Awwwards-level cinematic, immersive, and highly memorable digital experience that positions Modern Media & Marketing Consulting FZC as one of the top luxury creative agencies in the UAE.

### Constraints

- **Tech Stack**: Next.js, React, TypeScript, Tailwind CSS, GSAP, Lenis, Framer Motion, Three.js (where meaningful).
- **Design & Branding**: Primary: #234038 Deep Forest Green, Accent: #B88A44 Brass Gold, Background: #F7F4EC Warm Ivory, Cards: White, Text: Charcoal. Headings: Playfair Display, Body: Inter.
- **Performance**: High frame-rate animations (60fps), fast initial load times, optimized image loading, SEO best practices, accessibility (a11y) support.

## Technology Stack

## Recommended Stack

### Framework & Core Architecture

- **Next.js 14+ (App Router)**: High-performance React framework providing Server-Side Rendering (SSR) for optimal SEO, fast image optimization (`next/image`), and streaming UI capabilities.
- **TypeScript**: Strict type safety across components, animation configs, and content schemas.
- **React 18+**: Concurrent rendering and server components support.

### Styling & Design System

- **Tailwind CSS**: Utility-first CSS for rapid layout design, custom theme extending `#234038` (Deep Forest Green), `#B88A44` (Brass Gold), `#F7F4EC` (Warm Ivory), White, and Charcoal.
- **Typography**: Google Fonts integration via `next/font` for `Playfair Display` (Headings) and `Inter` (Body).

### Motion & Animation Architecture

- **Lenis Smooth Scroll**: Modern inertia-based smooth scrolling library for physics-based scroll feel.
- **GSAP & ScrollTrigger**: Industry standard for complex timeline animations, scroll pinning, parallax, text reveals, and image stacking.
- **Framer Motion**: Component-level gesture and page transition micro-interactions.
- **Three.js / React Three Fiber (R3F)**: Targeted 3D canvas integration for cinematic ambient visuals where meaningful.
